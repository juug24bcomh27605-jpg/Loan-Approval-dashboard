# Loan Approval Analysis Dashboard

## Files
- `app.py` — Streamlit dashboard
- `requirements.txt` — packages needed by the app

## Run on your computer
1. Install Python.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `streamlit run app.py`
5. Upload your dataset in the dashboard sidebar.

## Deploy with GitHub and Streamlit Community Cloud
1. Create a GitHub repository and upload `app.py` and `requirements.txt`.
2. Open Streamlit Community Cloud and connect your GitHub account.
3. Choose the repository, branch, and `app.py` as the main file.
4. Deploy the app.
5. Open the generated app URL and upload the dataset in the sidebar.

Status mapping used in this starter: code 0 = Approved and code 1 = Default. Verify this mapping against the original dataset documentation before submitting.
